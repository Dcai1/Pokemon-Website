## About This Website

This is a simple Pokémon site that displays various Pokémons from different regions in the official Pokémon games.

Built alone as a passion project, this was my first project as a developer, and I've been maintaining it and developing new features since then.

## Features

- Quick search for Pokémon by name
- Browse Pokémon by lookup
- Display Pokémon and their details
- Links to the Pokémon Database for additional information

The current functions of this website lists Pokémon on their respective pages. Clicking on one will display their details such as types, abilities, and locations.

### This small project was built using Next.js, React, TypeScript, TailwindCSS and the PokéAPI.
